Build a complete, polished, production-style full-stack web application called:

# SkillTrack — Employee Skill Management Platform

## 1. PROJECT OBJECTIVE

Build a realistic enterprise dashboard that helps organizations:

- Track employees
- Track employee skills
- Track skill proficiency levels
- Track certifications
- Track certification expiry dates
- Track employee training requirements
- Identify skill gaps
- Monitor employee learning progress
- View department-level skill analytics
- Recommend training based on skill gaps
- Monitor upcoming certification expirations
- Manage employee profiles and career development

This project is for an Employment & Career problem statement.

The final application must look like a **real SaaS product used by an HR/L&D department**, not like a basic college CRUD project.

The UI should be modern, professional, responsive, attractive, realistic, and presentation-ready.

IMPORTANT:
Build the application completely in ONE implementation.
Do NOT leave placeholder pages, broken buttons, fake navigation, TODO comments, or unfinished functionality.

Prioritize a working MVP with polished UI and realistic functionality over unnecessary advanced features.
